## DWF Renderer (`dwf-apk`) Oracle Integrity

None of the 9 `dwf-apk` renders are corrupted once `scripts/dwf-diff.py` polls `watchface op:status` until `frames >= 1` (larger APKs such as `casino-gshark` take ~2.5s to finish loading `res://` before drawing their first frame) and matches `supportedTypes` by Wear OS integer wire ID (`3=SHORT_TEXT`, `4=LONG_TEXT`, `5=RANGED_VALUE`, `13=GOAL_PROGRESS`).
