Every preview across every player: the baked capture (the catalog's own offline Robolectric/Skiko render, through AndroidX's embedded RcPlayer unless the preview pins the view-backed lane) next to the same ir/*.rc document as each player renders it. The JS player is the vendored TypeScript RC.RcdPlayer on a <canvas>; AndroidX Embedded · vendored Android is this repo's pinned and locally patched RcPlayer, rasterized by Robolectric; the cmp-jvm player runs that same RcPlayer draw path on Compose Desktop / Skiko, rasterizing offscreen; the cmp-wasm player runs the new Compose Multiplatform / Skiko player in browser Wasm — so they diverge wherever those differences show. Nothing is diffed until you ask for it: pick a column in Diff against and every other column grows a pixel diff plus a mismatch chip. Choosing the baked lane replays the build-time pixelmatch diffs; choosing a player diffs in the browser, which is how you compare two players directly. Rows sort worst-match-first on the worst-scoring player using the build-time scores in the header. A preview whose baked render is fully transparent is shown but not scored against it: with nothing in the reference, a player that draws nothing would score a perfect 0% — so those rows read no reference and stay out of the means.
