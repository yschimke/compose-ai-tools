Each row pairs a remote-m3 component with its declared wear-m3-catalog parallel (the parallel field in the catalog spec). Both renders are static thumbnails — the left from this branch, the right baked from the design-artifacts/wear-m3-catalog branch — and each links to the live preview server on click, where the component re-renders under other themes / locales / devices. A parallel that isn't catalogued in wear-m3-catalog yet is flagged unpaired. Components with no parallel on either side are listed below the table. The leading M3 Wear OS kit column is the published design reference BOTH implementations are reproducing, which is what lets a divergence be attributed to one of them rather than merely observed between them. It is contributed by whichever catalog carries the figma: mapping; rows where neither does read "no kit reference".

Only in remote-m3 11

  • IconIconographyThe standalone RemoteIcon primitive.
  • Typeface/SpecimenTypefaceFour branded Google Fonts families, each drawing its own name — geometric, script, grotesk, monospace. A lane that cannot resolve a named family renders four identical-looking lines.
  • Typeface/VariableWeightTypefaceOne variable font (Roboto Flex) at wght 100/400/700/1000, written into the document as font-variation settings. A lane that resolves the family but drops the axes renders four lines in one weight.
  • Typeface/VariableWidthTypefaceThe same variable font at wdth 25/100/151 — the axis nothing can fake, since no text API asks for a narrower face. Either the set widths differ or the axes were dropped.
  • Theme/TypographyThemeA type ramp read from RemoteMaterialTheme.typography.
  • Theme/ColorSchemeThemeColour-scheme swatches read from RemoteMaterialTheme.colorScheme.
  • Theme/SystemThemeSwatchesThemeSystem-theme swatches — the catalog's only document carrying ColorTheme operations, where a light and a dark colour live in the document and the player selects between them.
  • Shader/LinearGradientShadersDocument-level gradient shader fill; the middle stop is a named value the connector can recolour live. A remote-creation-compose primitive with no Wear Material 3 component peer.
  • WidgetContainer/SmallWidget ContainerThe Small (200×60dp) squircle widget container the Wear widget host draws around widget content — default surfaceContainerLow fill, 8dp padding, 26dp corners — rendered through the glance-wear WearWidgetPreview tooling wrapper.
  • WidgetContainer/LargeWidget ContainerThe Large (200×108dp) squircle widget container with the host's default background, carrying a title + supporting line.
  • WidgetContainer/GradientBackgroundWidget ContainerA Small container whose widget declares its own WearWidgetBrush background (vertical gradient) — the corner clipping over the brush is the point.
